## 🚀 Highlighted Work

### 🧠 Cognitive & Knowledge Workstations
*   [**maple**](https://github.com/parallized/maple)
    *解放大脑！为 AI 编码独特设计的 SDD（Software Design Document）看板工作台，提供远超传统文本的视觉构思体验。*
*   [**Recall**](https://github.com/parallized/Recall)  
    *自生长任意领域知识库 / 知识闭环中枢。集 Anki, Perplexity, NotebookLM, Obsidian 于一体，深度支持 MCP 与自动化 RAG 检索。*
*   [**human-disassembler**](https://github.com/parallized/human-disassembler)  
    *解决焦虑！基于自我访谈理论的 100 问拆解系统，在与 AI 实时交互的深度追问中完成人类精神世界的自我 Debug。*

### 🤖 Automation & Agent Tooling
*   [**Syndicator**](https://github.com/parallized/Syndicator)  
    *智能简历引擎：根据外部 JD（职位描述）自动从项目池和废旧简历中“按需组合”出命中率最高的绝佳简历。*
*   [**GoClaw**](https://github.com/parallized/GoClaw)  
    *个人定制 AI 现实出游助手：从网页抓取到出行方案聚合，一次点击得到完整的高品质现实活动规划。*
*   [**notion-project-tracker**](https://github.com/parallized/notion-project-tracker)
    *打通 IDE 与 Notion 的 Claude & Codex 项目管理 Skill：支持跨项目知识库自动沉淀、中文配置映射及结构化数据库同步。*
*   [**official-ds-mastra**](https://github.com/parallized/official-ds-mastra) / [**tencent-ds-nodejs**](https://github.com/parallized/tencent-ds-nodejs)  
    *DeepSeek 接入实践：涵盖官方 API 以及腾讯云 Open API 的 NestJS/Mastra 封装脚手架。*
